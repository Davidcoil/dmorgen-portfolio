# 0002: CSP עם 'unsafe-inline' לסקריפטים, בינתיים

תאריך: 2026-11-09.

Next מזריק סקריפטים inline להידרציה. CSP קפדני דורש nonce לכל בקשה דרך proxy.ts ו-`headers()`,
וזה מוסיף מורכבות לפני שיש מה להגן עליו. ההחלטה: CSP מלא על הכול חוץ מ-`script-src 'unsafe-inline'`.
עוברים ל-nonce בבריף נפרד לפני פתיחת הדלפק (תשלומים). עד אז אין קלט משתמש שמרונדר כ-HTML, ולכן אין וקטור XSS אמיתי.
