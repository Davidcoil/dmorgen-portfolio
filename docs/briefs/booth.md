# בריף 5: חדר הצילום

**מי:** Opus 5.5. **תלוי ב:** כלום. מנוע ההפצה הראשי, ולכן הוא קודם לדלפק.

## מטרה
`/he/booth` פתוח: מצלמת הדפדפן, מאמן פוזות שרץ על המכשיר, מסגרת עם החתימה, ותמונה אחת לשמירה. הכול בצד הלקוח. אפס שרת, אפס קרדיטים. השיתוף (כתובת + OG) מגיע בבריף 9; כאן התמונה נשמרת למכשיר.

## קבצים שמותר לגעת בהם
- `rooms/booth/room.json` (door → open), `rooms/booth/room.tsx` (השלד מהשרת: כותרת, הסבר, הטיפים כטקסט), `rooms/booth/booth.tsx` (client, נטען עצלנית עם `next/dynamic`), `rooms/booth/coach.ts` (לוגיקת הפוזות, פונקציות טהורות), `rooms/booth/tips.ts`
- `lib/i18n/dictionaries/*`: רק `house.booth` (חדש)
- `tests/coach.test.ts`: הפונקציות הטהורות (זווית כתפיים, סנטר, מרכוז) על נקודות סינתטיות
- `package.json`: מותר להוסיף `@mediapipe/tasks-vision` בלבד, ולטעון את המודל מה-CDN של MediaPipe רק אחרי לחיצה על "הדלק מצלמה". ה-CSP ב-`next.config.ts`: מותר להוסיף את דומיין ה-CDN ל-`script-src`/`connect-src` בלבד.

## התנהגות
- לפני הכול: טקסט. שבעה טיפי פוזות של דוד, בעברית ובאנגלית, גלויים לכולם בלי מצלמה (התאום הטקסטואלי, וגם SEO: "איך להצטלם טוב").
- כפתור "הדלק מצלמה" → בקשת הרשאה → וידאו חי בתוך מסגרת. בלי הרשאה: הודעה חמה והטיפים נשארים.
- המאמן: 3 הערות בזמן אמת, אחת בכל רגע (לא עשר): "סנטר קצת למטה", "כתף אחת לפנים", "תנשום, תחייך בעיניים". מופיעות כטקסט גדול, מוקראות ב-`aria-live`.
- "צלם": ספירה 3-2-1, תמונה ל-canvas, מסגרת דקה עם "להצטלם טוב זה להרגיש טוב." ו-dmorgen.com, כפתור "שמור" (הורדה) ו"עוד אחת".
- "הקריאה": שורה אחת שנבחרת מתוך 12 משפטים כתובים מראש לפי מה שהמאמן ראה (למשל: "חייכת בעיניים בפריים השלישי. זה הקטע."). בלי AI.
- שום דבר לא עולה לשרת. כתוב במפורש על המסך: "התמונה נשארת אצלך. לא ראיתי אותה, וזה בכוונה."
- `prefers-reduced-motion`: בלי אנימציית ספירה, רק מספרים.

## קריטריוני קבלה
- `npm run check` ירוק. התקציב בכניסה לא משתנה (החדר נטען רק ב-`/booth`).
- `/he/booth` עצמו: JS ראשוני עד 120KB gzip לפני לחיצת "הדלק מצלמה". המודל נטען אחרי.
- עובד ב-Chrome Android ו-Safari iOS (לבדוק ידנית, לכתוב ב-PR מה נבדק).
- Lighthouse נגישות 100.

להעלות תמונה לשום מקום. לשמור פנים. להשתמש ב-AI גנרטיבי. פילטרים שמשנים גוף או עור (רק אור, חום, ניגודיות, מסגרת).
