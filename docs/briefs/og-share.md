# בריף 9: תמונות שיתוף

**מי:** Codex (מודול מבודד). **תלוי ב:** כלום. בישראל התצוגה המקדימה בוואטסאפ היא מנוע ההפצה. כל דבר שמבקר יוצר מקבל תמונת OG משלו.

## מטרה
`ImageResponse` של Next (כבר כלול, אפס תלויות) מייצר תמונות 1200×630 בעיצוב הבית: לכל חדר, לכל חותם על הקיר, לכל מחשבה, ולכל תוצאה שתבוא (משחקים, חדר הצילום).

## קבצים שמותר לגעת בהם
- `lib/og/{theme,fonts,card}.tsx`: רקע לילה, אור בחלון, גופן Suez One (נטען כ-ArrayBuffer מ-`public/fonts/`, יש להוסיף את קובץ ה-TTF; רישיון OFL), שם הבית בפינה.
- `app/[lang]/[room]/opengraph-image.tsx`: שם החדר + השלט/התקציר.
- `app/[lang]/wall/[id]/opengraph-image.tsx`: הציטוט, השם, "מהקיר של דוד".
- `app/[lang]/thoughts/[id]/opengraph-image.tsx`: המחשבה.
- `app/[lang]/opengraph-image.tsx`: הכניסה. מחליף את `og-cover.jpg` הישן.
- `tests/og.test.ts`: `card()` מחזיר ReactElement עם הטקסט המקוצץ נכון (RTL, עד 140 תווים, שלוש נקודות).

## התנהגות
- RTL אמיתי: `direction: rtl` לעברית, יישור ימין, פיסוק במקום הנכון.
- קיצור טקסט ארוך, בלי לחתוך מילה.
- `runtime = 'nodejs'`, `revalidate` של יום לחדרים, לעד לחותמות (הן לא משתנות).
- משקל: תמונה עד 150KB. בלי תמונות רקע כבדות, רק גרדיאנט וטקסט.

## קריטריוני קבלה
- כל אחת מארבע הכתובות מחזירה PNG 1200×630 תוך פחות משנייה בקר.
- בדיקה ידנית ב-opengraph.xyz או בשליחה לוואטסאפ, צילום מסך ב-PR.
- `npm run check` ירוק.

## אסור
ספריות עיצוב. פנים של מבקרים בתמונות OG (רק טקסט). לשבור את ה-CSP.
