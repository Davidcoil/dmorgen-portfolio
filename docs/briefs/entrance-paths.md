# בריף 2: המסלולים מסדרים את הבית

**מי:** Opus 5.5. **תלוי ב:** כלום.

## מטרה
היום הבחירה בכניסה נשמרת ומציגה תשובה אחת. אחרי הבריף: הבחירה מסדרת את המפה מחדש (החדר הרלוונטי ראשון), מוסיפה שורה אישית מעל המפה, ומציעה פעולה אחת בסוף העמוד. אפקט IKEA בפועל.

## קבצים שמותר לגעת בהם
- `rooms/entrance/paths.tsx`, `rooms/entrance/room.tsx`
- `components/house/map.tsx` (קבלת prop אופציונלי `first?: string`)
- `lib/house/path.ts` (חדש): טיפוס `PathId`, קריאה/כתיבה ל-localStorage, פונקציה טהורה `orderRooms(rooms, pathId)`
- `lib/i18n/dictionaries/he.ts` ו-`en.ts`: רק בתוך `house.entrance.paths[*]` (להוסיף `mapLine`, `offer`) ו-`house.map`
- `tests/path.test.ts` (חדש)

## התנהגות
- `orderRooms`: החדר של המסלול ראשון, השאר לפי `order`. בלי מסלול: לפי `order`.
- ההעדפה נקראת בצד הלקוח בלבד. ה-HTML מהשרת זהה לכולם (תאום טקסטואלי יציב, מטמון יציב). מעבר ללא קפיצה: המפה מרונדרת מהשרת בסדר ברירת המחדל, ובצד הלקוח מסתדרת עם `layout` של framer-motion (כבר מותקן), ומכבדת `prefers-reduced-motion`.
- מעל המפה שורה אחת לפי מסלול (`mapLine`), למשל לשמחה: "סידרתי לך את הבית. הגלריה ראשונה, ואז הקיר, שם אנשים כתבו מה קרה אצלם."
- בסוף העמוד הצעה אחת (`offer`): שמחה = "הצלם של המשפחה" (שורה + כפתור לדלפק); עסק = "גוגל אותי"; AI = "מאחורי הקלעים"; סתם = "תמונה אחת ומחשבה אחת בשבוע" (כפתור לדלפק, בלי טופס עדיין); קפה = דלת הקפה.
- כפתור "דלג" נשאר. בלי בחירה, הבית נראה בדיוק כמו היום.

## קריטריוני קבלה
- `npm run check` ירוק. `tests/path.test.ts` בודק את `orderRooms` על שלושה מקרים.
- Lighthouse נגישות 100 נשמר. הכפתורים נשארים `<button>`.
- בלי JavaScript: העמוד זהה להיום, הקישורים עובדים.
- התקציב: תוספת JS של פחות מ-6KB gzip.
