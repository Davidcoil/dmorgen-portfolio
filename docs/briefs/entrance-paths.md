# בריף 2: המסלולים נותנים הצעה

**מי:** Opus 5.5. **תלוי ב:** כלום.

## מטרה
היום הבחירה בכניסה נשמרת, מציגה תשובה ומובילה ברגל לדלת הנכונה. אחרי הבריף: בסוף המסדרון ובעמוד החדר מופיעה הצעה אחת שמתאימה למסלול שנבחר.

## קבצים שמותר לגעת בהם
- `rooms/entrance/paths.tsx`
- `components/house/offer.tsx` (חדש, client): קורא את המסלול מ-`localStorage` (המפתח `house.path`) ומציג הצעה אחת
- `components/house/closed-door.tsx`: הצבת `Offer`
- `lib/i18n/dictionaries/he.ts` ו-`en.ts`: רק בתוך `house.entrance.paths[*]` (להוסיף `offer`, `offerCta`)
- `tests/offer.test.ts` (חדש): לכל מסלול יש הצעה בשתי השפות

## התנהגות
- שמחה = "הצלם של המשפחה". עסק = "גוגל אותי". AI = "מה אני בונה". סתם = "תמונה אחת ומחשבה אחת בשבוע". קפה = דלת הקפה. הכפתור מוביל לדלפק או לדלת הקפה.
- בלי בחירה: לא מוצגת הצעה.
- ה-HTML מהשרת זהה לכולם. ההצעה נכנסת בצד הלקוח, בלי קפיצה בפריסה (שומרים לה מקום).

## קריטריוני קבלה
- `npm run check` ירוק. Lighthouse נגישות 100 נשמר.
- תוספת JS של פחות מ-3KB gzip.

## אסור
להוסיף תלות. לשמור את המסלול בשרת או בעוגייה. לשנות את התשובות הקיימות. קופי מתאמץ: דוד מחק אותו פעם אחת.
